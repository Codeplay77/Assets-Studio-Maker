# Política de segurança

## Versões cuidadas

Só a versão mais recente recebe correções de segurança.

## O que mais importa

O editor roda no computador de cada pessoa e abre projetos `.asmproj` vindos de qualquer lugar. Ele
também tem um servidor MCP para agentes de IA, que vem desligado, aceita conexões só do próprio
computador e exige uma chave de acesso. Falhas nesses pontos são as mais graves: um projeto que
executa código ou apaga arquivos, ou um jeito de usar o servidor sem a chave.

## Como relatar

Não abra uma issue pública. Use a opção **Report a vulnerability** na aba
[Security](https://github.com/Codeplay77/Assets-Studio-Maker/security) do repositório, que deixa o
relato visível só para o mantenedor.

Conte o que encontrou, como reproduzir e o que alguém poderia fazer com a falha. O mantenedor
responde assim que puder, combina com você quando a correção sai e dá o crédito a quem relatou, se
você quiser.
